# Triage labels

| Role | Local Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified for agent work |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use these values when assigning triage state.
Wayfinding states `claimed` and `resolved` are separate workflow
values defined in `issue-tracker.md`.
