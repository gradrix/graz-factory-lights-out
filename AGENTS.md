## Agent skills

### Issue tracker

Issues live in version-controlled Markdown under `.scratch/<feature>/issues/`.
Public priorities live in `docs/roadmap.md`; update maintained guides in `docs/`
for user-facing behavior. Keep handoff, issues, and research portable in `.scratch/`;
keep raw runtime evidence in ignored `.gflo/`.
Before issue operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels.
Before triaging, read `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: root `CONTEXT.md` and `docs/adr/`.
Before exploring the codebase, read `docs/agents/domain.md`.
