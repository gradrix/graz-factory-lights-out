- Only HTML `EVENT_LIMIT`10000→40000 and extractor version changed in `document_extract.py`; body/text/depth/block and execution envelope code remain unchanged. Existing independent [event prototype](../../autonomy/document-event-prototype.md) established the exact body and paired limits; builder's current [actual pinned-container extraction](builder-asyncio.json) reports440spans/37712UTF8bytes with the same span hash in0.404seconds. That current Docker measurement was performed by the builder, not this review. Functional QA separately repeated event-cap controls. No claim that this reviewer repeated resource extraction on the rig.
- `response_answer` is the sole repair-eligibility classifier. It distinguishes envelope/authority problems from returned assistant-text validation; call exceptions pass through a cancellation/deadline check before becoming nonrepairable inference diagnostics. The measured cancellation `ValueError` does not fall through into an authorized retry.
- Format2 binds exact file set, regular owner/read-only/single-link files, byte sizes/hashes, contiguous attempts, deterministic request reconstruction, fixed profile and canonical result. It recursively resolves only an evidence-kind record, preventing an answer from serving as its own evidence. Unknown formats and malformed ledger state refuse. Format1 keeps the historical read path and does not trigger extraction/migration.
- `_publish` validates all private bytes, removes the pending marker privately, syncs and checks cancellation/deadline immediately before final rename. Rendered success output and failed-record exception are constructed before commit; stage ownership is cleared immediately afterward. Success and failure share this tested publication boundary.
- One monotonic260-second operation deadline covers reserve/calls/publication boundaries. Each child is capped at120seconds and at the remaining operation time minus10seconds for terminate/kill joins; caller additionally reserves one second before publication. The first- and second-call shortened-deadline controls exercise the remaining-budget branch. **A full260-second wall-clock run was not repeated.** Blocking host filesystem/kernel behavior is not a hard real-time guarantee, consistent with the builder's declared limit.
- Fixed fetch/guardian/sandbox/worker dependencies and authority were manifest-bound and unchanged. This slice adds no host mount, model credential exposure, source selection, browser/search operation or tool execution. Request/profile provenance contains endpoint/model metadata, not key contents.
