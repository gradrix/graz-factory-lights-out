## Threat model

The controller, fixed recipes/images, Docker daemon, limits and store parent are trusted. Model output, project manifests, package/archive bytes and executor output are untrusted. No untrusted concurrent host writer is assumed. Main assets are host credentials/files, controller availability, serving GPUs, immutable dependencies and receipt truthfulness. Hashes bind content; they do not certify dependency safety. Online acquisition is a fixed trusted HTTPS client using bridge networking, **not a network firewall**. Project/package execution is confined to offline executors. Approved task workspace writes remain part of the worker contract.
