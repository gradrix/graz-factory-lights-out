# Approved document evidence: first Stage4 slice

Author: agent, under the user-authorized local autonomy destination. This is a bounded first slice; the complete Stage4 ten-answer/five-browser-journey gate remains unchanged and unaccepted.

## Behavior

Provide a small CLI path for controller-approved exact public HTTPS documentation URLs: bounded trusted fetch, offline inert extraction, immutable evidence receipt, one fresh local-model answer with validated citations, and saved offline replay. The model has no fetch/publish/tool authority in this slice. Keep the existing application and local-only model client. No search, browser, crawler or new scheduler.

An approval file freezes exact URL and explicit source/version label (a floating series URL is not an exact runtime patch guarantee), optional expected SHA256 and question. URL approval covers full origin/path; reject query, fragments, credentials, non443 ports, control/nonASCII/backslash ambiguity. Reject all redirects and non200 statuses, mixed/nonpublic IPv4 DNS answers, unsupported encoding and malformed/oversize/incomplete responses. Resolve once, connect checked numeric address with original-host TLS. No ambient cookies, auth, proxies, project mounts, GPU devices or Docker socket. Approved pinned Python image, no pull, runc/nonroot, readonly root, bounded resources and owner-EOF cleanup. Preserve existing package-fetch allowlists and mandatory lock digests.

Fetch at most2MiB body plus8KiB framed metadata, with15seconds work deadline and explicit bounded guardian cleanup grace. Extract HTML/plainUTF8 offline, no assets/scripts/links executed or followed. Preserve raw body and deterministic numbered text spans; drop noncontent executable regions. Bounds:128KiB extracted text,10000parser events,depth64,2048blocks; reject instead of truncate. Extraction5seconds; cancellation/deadline fences include publication. Failures produce bounded diagnostics and no reusable partial evidence. Reject restrictive offline-retention directives(no-store/private/no-cache/must-revalidate/proxy-revalidate),Set-Cookie,unsupported/ambiguous policy. Historical snapshot display always reports retrievedUTC/version/age; no claim of present-day freshness.

Evidence identity binds approved request, URL, actual HTTP/cache facts, UTC retrieval, raw/text hashes/sizes, extractor/helper/image identity. Private controller store rejects traversal/links/special files/tampering/pending publication. Cleanup succeeds before commit; failed publication preserves prior valid records. Reserve staging headroom; cap16evidence records/64MiB with explicit full-store refusal and no implicit eviction. Use fixed filenames or a bounded canonical record; no generic artifact framework is required.

One tool-free local answer request uses frozen question/evidence, max2048outputtokens, medium reasoning with bounded thinking,120second request timeout; no cloud/fetch fallback. Require supported claims with exact quoted span citations or explicit insufficient-evidence. Validate structure/reference/span/excerpt and derive displayedURLs from receipt, never from model supplied links. Citation byte matching proves provenance, not logical entailment; independent semantic QA must check support. Save bounded answer receipt binding evidence/question/model/config/request/response and verdict. Saved offline replay needs neither network nor inference; missing/corrupt evidence is an explicit error. Explicit re-answer is a new inference, not replay.
